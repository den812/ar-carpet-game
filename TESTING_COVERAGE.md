## 🎓 Методология тестирования

### 1. Unit тесты
- Тестируют отдельные функции и методы
- Покрывают все ветки (branches)
- Покрывают edge cases

### 2. Integration тесты
- Тестируют взаимодействие модулей
- Полный жизненный цикл объектов
- Реальные сценарии использования

### 3. E2E тесты
- Тестируют приложение целиком
- Playwright для браузерного тестирования
- UI взаимодействия

## 🐛 Известные ограничения

1. **GLB модели**: В тестах используются моки, реальные модели не загружаются
2. **WebXR**: AR-режим не тестируется в unit-тестах (только E2E)
3. **Визуализация**: Three.js рендеринг не тестируется напрямую
4. **Браузерные API**: localStorage не используется (ограничение artifacts)
