# Debug roads layer (from code)

**Version: v11.1 (2026-01-13)**

This temporary debug overlay visualizes the *exact* road paths exported from `assets/generated_network.json` (generated by the code), not the manual `carpet-scan-roads-only.jpg`.

## Files
- `assets/carpet_roads_from_code_overlay.png` — transparent overlay with roads from JSON.
- `assets/carpet_scan_alpha.png` — carpet texture with transparent white zone.
- `assets/carpet_roads_alpha.png` — roads-only texture with alpha (optional for dev).
- `assets/models/carpet_plane_*.obj/.mtl` — MM-scaled planes (long side 3000 mm).
- `assets/debug/*_mask_preview.png` — mask preview images.

## Notes
- Coordinate system: Right-bottom is origin (0,0,0), X left, Y up, long side = 3000 mm.
- Overlay is **for debugging only**; remove or disable in production.
