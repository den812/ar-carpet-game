# Debug roads layer (from code)

**Version: v11.2 (2026-01-13)**

Этот временный слой визуализирует *именно те* дорожные пути, которые экспортирует код в `assets/generated_network.json` — не вручную подготовленный `carpet-scan-roads-only.jpg`.

## Файлы
- `assets/carpet_roads_from_code_overlay.png` — прозрачный оверлей дорог, построенный из JSON.
- `assets/carpet_scan_alpha.png` — текстура ковра с прозрачной белой зоной.
- `assets/carpet_roads_alpha.png` — текстура roads-only (опционально для разработки).
- `assets/models/carpet_plane_*.obj/.mtl` — плоскости в миллиметрах (длинная сторона 3000 мм).
- `assets/debug/*_mask_preview.png` — предпросмотры масок.

## Примечания
- Система координат: правый нижний угол (0,0,0), X влево, Y вверх; длинная сторона = 3000 мм.
- Слой предназначен **только для отладки**; в проде отключить/удалить.

## Тесты
Юнит-тесты данные-зависимые: пороги не захардкожены, читают фактические размеры из `generated_network.json`. При `showRoads=true` проверяется, что `parent.add(...)` вызывается и слой непустой.
